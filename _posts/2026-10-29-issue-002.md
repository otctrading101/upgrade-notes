## 1. Railway's breach report: rotate your secrets if you signed up before Oct 21
**Oct 22, updated Oct 26 · Railway**

Railway's preliminary report says an attacker was inside parts of its systems from Oct 20 13:58 UTC to Oct 22 03:32 UTC, pulled customer environment variables, and decrypted a subset of them using credentials taken from Railway's CI. Railway believes the goal was AI provider API keys, to use for distillation attacks. It recommends that every customer who signed up before Oct 21 rotate the keys stored on Railway. If you host there, rotate your OpenAI, Anthropic, Stripe and database credentials, reconnect GitHub, create new CLI and CI tokens, and check your provider dashboards for usage you don't recognize.

Source: [Railway preliminary report](https://blog.railway.com/p/preliminary-report-october-security-incident) · [Original disclosure](https://blog.railway.com/p/security-disclosure-wednesday-october-21st)

## 2. An AGENTS.md in your Downloads folder can take over your coding agent
**Oct 25 · Security**

Researchers at Forever Security traced a coding agent's attempt to install a malicious npm package to an AGENTS.md file sitting in a customer's `~/Downloads` folder, which was also the agent's working directory. A web page can drop a file there without asking in Chrome, Edge and Firefox. They reproduced it against Codex (about 90% success with a harmless payload) and used a malicious CLAUDE.md to redirect Claude Code's API traffic and expose its OAuth token. Nobody has a patch to ship here: start agents in the project folder, never in Downloads or your home directory, and read any instruction file you didn't write.

Source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/ai-coding-agents-hijacked-using-agentsmd-file-in-downloads-folder/)

## 3. Connecting to a bad MCP server could run code on Windows: OpenCode and MCP Inspector
**Oct 19–22 · Security**

A remote MCP server picks the OAuth sign-in URL your client opens. OpenCode on Windows and WSL passed that URL into PowerShell unescaped, so a normal-looking https link could run code during sign-in. It was fixed in 1.18.33 with no advisory or CVE, so dependency scanners won't flag it. MCP Inspector had the same bug class (fixed in 2.12.0) and a separate OAuth callback bug that ran local commands on any OS (fixed in 1.0.3). Upgrade both, and remove remote MCP servers you haven't vetted.

Source: [Pillar Security](https://www.pillar.security/blog/open-and-shut-remote-code-execution-in-opencode-via-mcp-oauth) · [GHSA-q978-78c7-phqw](https://github.com/modelcontextprotocol/inspector/security/advisories/GHSA-q978-78c7-phqw) · [GHSA-4fc4-wcmh-4g86](https://github.com/modelcontextprotocol/inspector/security/advisories/GHSA-4fc4-wcmh-4g86)

## 4. GitHub Universe: Actions lockfiles and agentic workflows go GA
**Oct 28 · GitHub**

Workflow lockfiles are now generally available on Free, Team and Enterprise Cloud. The `gh actions-lock` extension writes `.github/workflows/actions.lock`, so your workflows keep readable tags but run the exact commits you locked, and Dependabot updates the lockfile in the same PR. GitHub Agentic Workflows also went GA: you write the automation in Markdown, it compiles to Actions YAML, and agents run read-only by default inside a sandboxed container behind a firewall. Push protection can now block secrets without a known format using an AI classifier (public preview, off by default), and code scanning for AI apps flags prompt-injection paths in PRs (public preview, needs Advanced Security).

Source: [Workflow lockfiles GA](https://github.blog/changelog/2026-10-28-github-actions-workflow-lockfiles-are-generally-available) · [Agentic Workflows GA](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available) · [AI-detected secret push protection](https://github.blog/changelog/2026-10-28-push-protection-beyond-predefined-secret-patterns) · [Code scanning for AI applications](https://github.blog/changelog/2026-10-28-code-scanning-for-ai-applications-in-public-preview)

## 5. Copilot now comes with GitHub Enterprise, billed by usage
**Oct 28 · GitHub**

Enterprises that work with a GitHub or Microsoft account team can now get Copilot included for every GitHub Enterprise user. AI usage is metered against the enterprise budget from the first request, with no per-seat monthly credits. Completions and next-edit suggestions keep working with no budget left, but Chat, code review and the cloud agent need budget. Self-serve customers can't get it yet, and Copilot Business and Enterprise are still sold. If you run an enterprise account, set budget alerts before you switch.

Source: [GitHub Changelog](https://github.blog/changelog/2026-10-28-github-enterprise-now-includes-access-to-github-copilot)

## 6. OpenAI ships GPT-6.1 Terra and gives Pro and Business plans API credits
**Oct 26–28 · OpenAI**

GPT-6.1 Terra is out on the Responses and Chat Completions APIs, pitched as a fast, cheaper model for visual reasoning, computer use and writing. OpenAI's model page lists $1 input and $5 output per million tokens with a 1,050,000-token context window, and GitHub made it generally available in Copilot the same day. Starting Oct 28, eligible ChatGPT Pro and Business subscribers can link an API organization they own and get up to $500 a month in free API credits. Unused credits expire at the end of each billing cycle. Also, the Decisions API went GA on Oct 22 with up to 400 questions per request.

Source: [OpenAI API changelog](https://developers.openai.com/api/docs/changelog) · [GPT-6.1 Terra model page](https://developers.openai.com/api/docs/models/gpt-6.1-terra) · [API credits for ChatGPT subscribers](https://developers.openai.com/api/docs/guides/chatgpt-api-credits) · [Terra in Copilot](https://github.blog/changelog/2026-10-26-gpt-6-1-terra-in-github-copilot)

## 7. Gemini API now stores requests by default on new paid projects
**Oct 26–27 · Google**

New paid-tier projects that use `generateContent`, `streamGenerateContent` or `batchGenerateContent` now store requests by default (`store=true`). Existing projects keep their current setting. If you're starting a new project and handle user data, send `store=false` per request or turn off Generate Content API logging in the Logs and Datasets settings. Google also released `gemini-api`, a zero-dependency command-line client (beta) built for coding agents, scripts and CI.

Source: [Gemini API release notes](https://ai.google.dev/gemini-api/docs/changelog) · [Logs and datasets](https://ai.google.dev/gemini-api/docs/logs-datasets) · [Gemini API CLI](https://ai.google.dev/gemini-api/docs/cli)

## 8. Claude Code 2.1.309–2.1.312 and Codex 0.164–0.165: sandbox fixes and credential masking
**Oct 22–27 · Anthropic, OpenAI**

Claude Code 2.1.309 fixed sandboxed Bash running your shell startup files outside the sandbox and sandboxed commands being able to modify the `--mcp-config` file. It also made `claude ultrareview` require workspace trust, so scripts need `--trust-workspace`. Version 2.1.311 stops standard-context sessions from dying with "Usage credits required for 1M context" by compacting instead. Codex 0.164 masks credentials in supported remote Bash commands and adds `/presets`. Codex 0.165 adds a built-in Vertex AI provider (`model_provider = "gcp"`) and closes a marketplace URL check that could let Git connect to a different host.

Source: [claude-code v2.1.309](https://github.com/anthropics/claude-code/releases/tag/v2.1.309) · [v2.1.311](https://github.com/anthropics/claude-code/releases/tag/v2.1.311) · [codex 0.164.0](https://github.com/openai/codex/releases/tag/rust-v0.164.0) · [codex 0.165.0](https://github.com/openai/codex/releases/tag/rust-v0.165.0)

## 9. Open weights this week: Ling-3.1-flash-1019 and Liquid's LFM3
**Oct 27 · Open models**

inclusionAI posted Ling-3.1-flash-1019 on Hugging Face under the MIT license: 560B total parameters, 25B active, a 1M-token context window, plus a base model for your own post-training. Liquid AI released LFM3, six models around 2B parameters (text, vision, audio, omni and two "decision" models) built to run on-device. The text model fits in about 1 GB at 4-bit. Check LFM3's license first, because the LFM Open License limits commercial use to companies under $10M in annual revenue. Mistral Large 4's weights, promised for the end of October, were still a placeholder on Hugging Face as of Thursday morning.

Source: [Ling-3.1-flash-1019](https://huggingface.co/inclusionAI/Ling-3.1-flash-1019) · [LFM3 announcement](https://huggingface.co/blog/LiquidAI/lfm3) · [Mistral Large 4 placeholder](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B)

## One thing to try this week

Pin the exact commits your GitHub Actions run, so a moved tag can't swap code under you:

```bash
gh extension install github/gh-actions-lock
gh actions-lock
```

Review the generated `.github/workflows/actions.lock` and commit it. Then check that you aren't starting coding agents from `~/Downloads` or your home directory: `cd` into the project first.
